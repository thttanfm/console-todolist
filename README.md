# 待办事项管理命令行程序

一个用 Python 编写的轻量级命令行待办事项管理工具。支持任务的添加、删除、更改与查看，所有数据以 JSON 格式持久化保存，无需任何第三方依赖。

---

## 功能特性

- **字母菜单交互**：所有菜单以 `a. 选项 / b. 选项 ...` 的形式呈现，输入字母即可选择。
- **可扩展的数据结构**：字段定义集中于 `ITEM_FIELDS`，新增字段（如优先级、备注、分类等）只需改动一行配置。

---

## 环境要求

- Python 3.6 及以上
- 仅使用标准库（`json`、`os`、`re`、`datetime`），无需 `pip install`

---

## 快速开始

1. 在终端中运行：

```bash
python main.py
```

2. 程序启动后进入主菜单，按提示输入字母进行操作即可。

## 使用说明

### 主菜单

```
=== 待办事项 ===
a. 查看待办事项
b. 修改待办事项
c. 设置
d. 退出
```

| 选项 | 说明 |
| --- | --- |
| `a` | 列出所有待办事项（按当前排序设置显示），按回车返回主菜单 |
| `b` | 进入修改子菜单 |
| `c` | 进入设置页 |
| `d` | 退出程序 |

### 修改待办事项子菜单

```
=== 修改待办事项 ===
a. 添加
b. 删除
c. 更改
d. 返回主菜单
```

- **添加**：依次输入名称和截止日期。
- **删除**：先显示所有条目（带数字编号），输入要删除的编号。
- **更改**：先选择条目编号，再逐个字段输入新值；直接回车可保留原值。

> 注意：条目编号是基于**当前排序视图**的。排序不会改动数据本身的顺序，删除和更改时会正确对应到你看到的条目。

### 设置页

```
=== 设置 ===
当前排序方式：不排序
a. 设置排序方式
b. 返回主菜单
```

选择 `a` 后可选择排序方式：

- 不排序（按添加顺序）
- 按时间正序（截止日期由早到晚）
- 按时间倒序（截止日期由晚到早）

> 未填写或格式异常的日期在排序时会被排到最后。

### 日期输入规则

- 输入格式必须严格为 `yyyy-mm-dd`，例如 `2025-10-20`。
- 程序会校验日期是否真实存在（如 `2025-02-30` 会被拒绝）。
- 若输入的日期早于今天，会弹出警告并询问是否确认提交：

```
警告：2025-01-01 已经过去，确定要提交吗？(y/n) >
```

## 数据存储

程序运行时会在脚本所在目录生成（或读取）以下文件：

### `data.json` —— 待办事项数据

```json
[
  {
    "name": "写周报",
    "due_date": {
      "year": 2025,
      "month": 10,
      "day": 25
    }
  },
  {
    "name": "购买生日礼物",
    "due_date": {
      "year": 2025,
      "month": 11,
      "day": 3
    }
  }
]
```

- 顶层为数组，每个元素是一条待办事项（对象）。
- 日期字段为对象，年、月、日分别存储，未做前导零补齐。
- 文件损坏或不存在时，程序会以空列表开始，不会崩溃。

### `settings.json` —— 用户设置

```json
{
  "sort": "asc"
}
```

| `sort` 取值 | 含义 |
| --- | --- |
| `none` | 不排序 |
| `asc` | 按时间正序 |
| `desc` | 按时间倒序 |

设置与数据分离存储，`data.json` 保持纯数组格式，向后兼容旧版本数据。

## 扩展指南

### 增加新的待办事项字段

找到配置区的 `ITEM_FIELDS`：

```python
# (字段名, 显示名称, 字段类型, 是否必填)
ITEM_FIELDS = [
    ("name", "名称", "text", True),
    ("due_date", "截止日期", "date", True),
]
```

例如添加「优先级」字段，只需追加一行：

```python
    ("priority", "优先级", "text", False),
```

无需修改展示、添加、修改等逻辑，程序会自动适配。若要支持更多字段类型（如 `int`、`bool`），可在 `add_todo` / `modify_todo` 中按 `ftype` 增加对应的输入分支。

### 调整排序键

修改 `_date_key(item)` 函数即可改变排序依据（例如改为按优先级排序）。

## 常见问题

**Q：数据文件保存在哪里？**  
A：与 `todo.py` 同一目录下的 `data.json` 和 `settings.json`。移动脚本时请一并移动数据文件。

**Q：可以手动编辑 `data.json` 吗？**  
A：可以。保持文件为合法的 JSON 数组即可，程序每次启动都会重新读取。

**Q：为什么修改条目后编号变了？**  
A：因为你可能处于「按时间排序」模式。排序只影响显示，数据本身顺序不变，编号按当前显示顺序计算。

**Q：如何彻底清空数据？**  
A：删除 `data.json` 即可（或将其内容改为 `[]`）。`settings.json` 可单独保留以维持排序偏好。
